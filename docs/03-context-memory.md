# 🧠 הקשר (Context) וזיכרון

<p align="center"><sub>פרק 3 מתוך 8 · Claude Code בעברית · מעודכן לאוקטובר 2026</sub></p>


## שתי מערכות זיכרון שונות לגמרי

### 1. זיכרון אוטומטי (Claude מנהל)
- פעיל כברירת מחדל.
- יושב ב־`~/.claude/projects/<repo>/memory/MEMORY.md` (וקבצים לצידו).
- מקומי למחשב, **לא נכנס ל־git**.
- רק **200 השורות / 25KB הראשונים** של `MEMORY.md` נטענים אוטומטית – לכן הוא אמור להיות אינדקס, לא מאגר.
- מדליקים/מכבים ב־`/memory`.

### 2. מסמך זיכרון בריפו (אתם מנהלים)
- קובץ בריפו, נכנס ל־git, עובר Code Review.
- בדרך כלל מיובא מ־CLAUDE.md עם `@` (ונטען במלואו).
- נוסע עם הפרויקט ותקף לכל חברי הצוות.

**כלל אצבע:** דברים אישיים/זמניים → זיכרון אוטומטי. החלטות צוות → מסמך בריפו.

## ממה מורכב חלון ההקשר?

> **הוראות מערכת** + **CLAUDE.md** + **קבצים שנקראו** + **זיכרון שנטען** + **Skills** (תיאורים) + **הגדרות כלים ו־MCP** + **היסטוריית השיחה**

### &rlm;`/context` – הפקודה הראשונה שכדאי להריץ

מציגה רשת צבעונית של מה שתופס מקום בחלון **בתור הזה**, עם המלצות לחיסכון. רוב האנשים מגלים משהו גדול שנטען תמיד בלי סיבה (שרת MCP עם 80 כלים, Skill ענק…).

- &rlm;**`/skill-doctor`** – מראה כמה כל Skill עולה בהקשר וכמה פעמים הוא בשימוש, כדי למצוא מה לכבות.
- &rlm;**`/skills`** – לחצו `t` למיון לפי מספר טוקנים.

## ניהול השיחה

| פקודה | מתי |
|-------|-----|
| `/compact [הנחיות]` | אותה משימה, ההיסטוריה ארוכה – מסכם ומשחרר מקום. אפשר לכוון: `/compact התמקד בהחלטות על ה-API` |
| `/clear [שם]` | משימה אחרת – מתחילים נקי (השיחה הקודמת נשמרת ב־`/resume`) |
| `/autocompact [auto\|500k]` | קובע מתי דחיסה אוטומטית מופעלת |
| `/branch [שם]` | פיצול השיחה כדי לנסות כיוון אחר בלי לאבד את הנוכחי |
| `/rewind` (גם `/undo`) | חזרה לנקודה קודמת – בשיחה ו/או בקוד |
| `/btw [שאלה]` | שאלת צד על הסשן בלי להוסיף להקשר |
| סשן חדש | כשהסשן "התבלבל" – אל תסחבו את הבלבול הלאה |

## אמת חשובה על אחזור (Retrieval)

**אין מסד נתונים וקטורי, אין embeddings, אין אינדקס סמנטי.** Claude Code מחפש ב־grep וקורא קבצים – בדיוק כמו מפתח אנושי.

המשמעות: **מבנה תיקיות ברור ושמות קבצים מדויקים** שווים יותר מכל טכניקת אחזור. קובץ בשם `utils2_final.ts` הוא בעיית הקשר.

## עלות ההקשר

כל מה שנטען אוטומטית הוא **"שכר דירה" שמשלמים בכל תור**. מה שרלוונטי תמיד – ב־CLAUDE.md. מה שרלוונטי לפעמים – ב־`.claude/rules/` או ב־`docs/`.

החל מאוגוסט 2026 יש **מד Cache** בממשק, ומספטמבר הוא גם מציג **סיבה משוערת** לכל פספוס cache – שימושי כדי לגלות מה שובר לכם את ה־prefix.

## מודלים עם 1M טוקנים

&rlm;Opus 5.5, Sonnet 5.5 ו־Fable 5.1 תומכים ב־**מיליון טוקנים** כברירת מחדל. זה לא אומר שצריך למלא אותם – חלון מלא = איטי ויקר יותר, ואיכות הקשב יורדת. `CLAUDE_CODE_DISABLE_1M_CONTEXT=1` מחזיר ל־200K.
