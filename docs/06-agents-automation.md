## סולם ההאצלה

ככל שעולים בסולם, אתם מתארים פחות "איך" ויותר "מה":

| אתם... | הכלי |
|--------|-------|
| מקלידים הודעה | שיחה רגילה |
| מתארים משימת צד | **Subagent** – חלון הקשר משלו, מחזיר סיכום |
| מעבירים משימות עצמאיות לרקע | **Agent view** (`claude agents`) – סשנים ברקע |
| מתארים צוות | **Agent Teams** – מוביל + חברי צוות, רשימת משימות משותפת |
| מתארים תוכנית חוזרת | **Dynamic Workflow** – סקריפט מחזיק את התוכנית |
| מתארים מטרה מתמשכת | **Routine** / **Managed Agent** – רץ בלעדיכם |

## Subagents

מוגדרים כקבצי Markdown ב־`.claude/agents/` (פרויקט) או `~/.claude/agents/` (אישי):

```markdown
---
name: security-reviewer
description: סוקר שינויים לבעיות אבטחה. השתמש אחרי שינויים ב-auth או ב-API.
tools: Read, Grep, Glob
model: sonnet
---
אתה סוקר אבטחה. חפש injection, דליפת סודות, בדיקות הרשאה חסרות...
```

- חובה: `name` ו־`description`. אופציונלי: `tools`, `model`.
- רצים בהקשר מבודד ומחזירים סיכום – הסשן הראשי נשאר נקי.
- מצוין לחוות דעת שנייה, נקודות מבט מקבילות, וסקירה לקריאה בלבד.
- **`/subtask <משימה>`** – Subagent ברקע שיורש את **כל** השיחה (fork).
- **`/agents`** כבר לא פותח ממשק – פשוט בקשו מ־Claude "צור subagent ש..." או ערכו את הקבצים.

## Agent view וסשנים ברקע

- **`claude agents`** – מסך אחד שמציג את כל הסשנים ברקע, את מצבם ומי מחכה לכם (Research preview).
- **`/background`** – מנתק את הסשן הנוכחי לרקע. **`/fork`** – מעתיק את השיחה לסשן רקע חדש וממשיך כאן.
- סשנים שנשלחים מ־agent view עוברים אוטומטית ל־**worktree** משלהם לפני שהם עורכים קבצים.

### הודעות בין סשנים *(חדש, ספטמבר 2026)*

Claude יכול לשלוח הודעות לסשנים אחרים שלכם – באותו מחשב, במחשב אחר או בענן – כדי להעביר ממצאים במקום להעתיק הקשר בין טרמינלים. **`/list-agents`** מציג עם מי אפשר לדבר. בהקלדת `@` ואות, מוצעים גם סשנים חיים.

## Agent Teams

- **ניסיוני וכבוי כברירת מחדל**; מופעל דרך משתנה סביבה ב־`.claude/settings.json`.
- מוביל + חברי צוות שמתכתבים ישירות וחולקים רשימת משימות.
- עולה הרבה יותר טוקנים. חברי הצוות **לא** מבודדים ב־worktrees – חלקו את העבודה כך שכל אחד אחראי על קבצים אחרים.

## Dynamic Workflows

סקריפט JavaScript ש־Claude כותב, והוא מתזמר הרבה Subagents. ההבדל המהותי: **הסקריפט מחזיק את התוכנית**, לא Claude תור־אחר־תור. תוצאות ביניים נשארות במשתני הסקריפט ולא ממלאות את ההקשר.

**איך מפעילים:**
- `/deep-research <שאלה>` – Workflow מובנה למחקר עם הצלבת מקורות.
- לכתוב בבקשה "use a workflow ..." או להוסיף את מילת המפתח **`ultracode`** ל־prompt.
- `/effort ultracode` – Claude מתכנן Workflow לכל משימה משמעותית בסשן (יקר!). מספטמבר 2026 זה **מתג נפרד** מרמת ה־effort.

**מעקב:** `/workflows` – שלבים, סוכנים, טוקנים. `p` להשהיה, `x` לעצירה, `s` לשמירה כפקודה ב־`.claude/workflows/`.

**מגבלות:** עד 16 סוכנים במקביל כברירת מחדל (`CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`), עד 1,000 סוכנים לריצה. אזהרת `Large workflow` מעל 25 סוכנים או 1.5M טוקנים.

**דוגמאות טובות:** סריקת כל ה־routes לבדיקות auth חסרות, מיגרציה של 500 קבצים, "תריץ tsc ותתקן עד שעובר".

## Routines מול Cowork

| | Routine | Cowork |
|--|---------|--------|
| קשור ל | ריפו ב־GitHub | כלים מחוברים |
| מייצר | Pull Requests | תדריכים, טיוטות, פעולות |
| יכול | לשכפל קוד, להריץ בדיקות | לקרוא/לכתוב Gmail, Notion, Slack, Drive |
| טריגרים | תזמון, API, אירוע GitHub | תזמון |

**כלל:** התוצר הוא שינוי בריפו? → Routine (`/schedule`). אחרת → Cowork.

עוד כלים קרובים:
- **`/loop [מרווח] [prompt]`** – חזרה כל עוד הסשן המקומי פתוח.
- **`/autofix-pr`** – סשן ענן שעוקב אחרי PR ודוחף תיקונים כש־CI נכשל או כשיש הערות.
- **`/goal [תנאי]`** – Claude ממשיך לעבוד עד שהתנאי מתקיים.

## Managed Agents

Anthropic מארחת את הלולאה, ה־sandbox והכלים – Agent SDK בלי שרתים. כולל מאגרי זיכרון (ברמת workspace ולכל משתמש) שנשמרים בין סשנים.

**עלות:** טוקנים לפי מחירון ה־API + **$0.08 לשעת סשן פעילה** (זמן המתנה לא נספר).

**הכלל המבחין:** אתם מתזמנים מול ריפו → Routine. המשתמשים שלכם מפעילים מתוך מוצר → Managed Agent.

## בחירה מהירה

| צריך... | בחרו |
|---------|-------|
| חוות דעת שנייה בלי ללכלך את השיחה | Subagent |
| כמה נקודות מבט במקביל | Subagents / Agent Teams |
| כמה משימות עצמאיות שאני רק בודק | Agent view |
| אותו תהליך רב־שלבי שוב ושוב | Workflow (ושמירה כפקודה) |
| PR לפי לוח זמנים | Routine |
| תדריך או פעולה בין כלים | Cowork |
| משתמש שמפעיל מתוך מוצר | Managed Agent |

## טעויות נפוצות

- צי שלם של סוכנים כשמספיק Subagent אחד.
- סוכן חופשי כשבעצם צריך Workflow דטרמיניסטי.
- לשכוח **תנאי עצירה**.
- לאטמט משהו שמעולם לא עשיתם ידנית.
